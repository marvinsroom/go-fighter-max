# Sitcom Fighter

This collection is separate from the main Manga vs Manhwa game.

- Will
- Prince / Rick James
- Tyrone / Negan
- Urkel / Stefan
- Yamal

Open **Launch Sitcom Fighter.cmd** for character selection. Individual **Play** and **Fight CPU** launchers are in this folder. [Character reviews and controls](roster.html).

The character artwork, source packages, native move files and existing recordings were moved intact. This folder has its own engine configuration and five-fighter roster. The main game contains 23 manga/manhwa fighters.

Earlier launchers and cross-game scenarios are preserved under `archive/launchers`; use the working launchers in this folder. The pre-split roster, README and validation reports are preserved under `before`.
