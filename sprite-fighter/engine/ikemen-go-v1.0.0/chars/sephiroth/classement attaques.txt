Techniques "statut" attaques :

hell gate : provoque paralysie temporaire

cheval pâle : provoque l'état grenouille

bio : provoque l'état poison

time : ralenti l'ennemi

ankou : provoque mort instantanée (20% de chance) (50% avec l'ange sans coeur)

aura fence : vide entierement les sp de l'ennemi

glace paralysante : gel l'ennemi (peut être un coup mortel)

deen : provoque silence (empeche l'ennemi de faire certains coups et le bloque)
