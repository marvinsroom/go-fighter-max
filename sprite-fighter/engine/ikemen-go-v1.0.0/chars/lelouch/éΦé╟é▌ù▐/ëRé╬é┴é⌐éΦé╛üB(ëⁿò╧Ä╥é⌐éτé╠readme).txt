--AIについて---------------------------------------------------------------------
このキャラはＡＩ常時起動になっています。人操作に切り替えたい時は
lelouch.cnsを開いて、
trigger51 = 1 ;人操作に切り替えたい時は左端に;を追加。
の所を
;trigger51 = 1 ;人操作に切り替えたい時は左端に;を追加。
の様に切り替えてください。
また、コマンドはlelouch.cmdを参照してください。
---------------------------------------------------------------------------------

--スイッチについて---------------------------------------------------------------
lelouch.cns内を「コンフィグ」で検索すると、ゲージ技自重スイッチがあります。
onにすると一部のゲージ技を相手と一定以上離れており、なおかつ相手がやられ状態の時
のみしか使用しなくなります。
弱体化カラーではさほど変わりませんが、1Pは自著onで狂最上位中堅以上、自重offで狂上
位上限～狂最上位下層まで変動します。(自重onの方が強いです。勘違いなさらぬよう)
