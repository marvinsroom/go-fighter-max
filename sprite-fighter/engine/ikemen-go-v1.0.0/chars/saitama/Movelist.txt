Saitama by BoyBoyz (March 2017):

*He has superarmor (search 'superarmor' in the .cns and remove all the "null").
He can be injured by pressing and holding start button, but cannot be killed.
He has no gethit voices, because he feels no pain.
He has 5 winposes with 8 randomly triggered voices
He has 5 intros with 4 randomly triggered voices


Misc:
start / hold start button - taunt and become hittable. Let go start button and he will regain full life.
F or B + y/b = throw

Supers:
NEW: D,DB,B + a - whirling butt attack used on Suiryu in latest manga. Can move forward / backward, and is unblockable.
NEW: D,DB,B + x - homes in on enemy, unblockable kick into signature Saturday Sale Uppercut
NEW: D,DB,B + y - unblockable close grab move. Crushes the balls of enemy!
NEW: D,DB,B + b - unblockable move, where he punches the rain away!
NEW: D,DB,B + c - second version of serious sidehops, credits to Cliff for the code
D,DF,F + x - death punch (counter). unblockable.
D,DF,F + y - consecutive normal punches. can be done in air. unblockable.
D,DF,F + z - serious punch. unblockable.
D,DF,F + a - serious table flip (does not kill enemy, but minuses all their HP and makes them dizzy for 200 ticks). unblockable.
D,DF,F + b - serious headbutt. unblockable.
D,DF,F + c - serious sidehops. unblockable
D,DB,B + z - meteor punch

Special Moves:
NEW: D + x - one inch punch
NEW: D + y - homing air chop (can be done in air)
NEW: D + b - elbow (used on Hammerhead)
NEW: D + x (in air) - moon crash. Can only activate after jumping past a certain height. The shockwave is blocked low.
NEW: B, + y - King helper (2 random moves): Runs from behind enemies to hit them (blockable); or does an invisible full length move (unblockable, no dmg, stuns)
NEW: B, + b - Silver Fang helper. Charges across screen with flurry of punches. Blockable
B, + z - Genos helper. blockable fireball that does lower damage.
B, + c - Tatsumaki helper. Randomly summons tornado or meteor. Both are homing and blockable (meteor block high), dealing lower damage
D + c - Underground move (unblockable)
D,D + x/y - near/far teleport forward
D,D + a/b - near/far teleport backward

Normal Moves:
NEW: standing c - The "OK" dialogue will hit enemies. Unblockable and dizzies enemies, but no damage.
air kicks have slight autoguard at startup.
buttons y, z, b, c are unblockable normals.
