# Naruto and Saitama illustrated conversion: in progress

Open [review.html](review.html), or `Review Naruto and Saitama Style Conversion.cmd` in the sprite-fighter folder. It explicitly previews candidate artwork rather than claiming an installed conversion.

24 of 72 planned animation sheets are saved, representing 526 unique source poses. Every Naruto bank has initial illustrated artwork: base, Sage, Ashura, KCM1, KCM2, four tails, six tails and Kurama (including the source avatar variations). Saitama and his existing Genos/Tatsumaki/King/Silver Fang assists have initial sheets. Gold Naruto hair was corrected to short spikes and two thin headband ties.

The built-in image generator returned `usage_limit_reached`. Another 48 animation sheets and both HUD portraits are still pending. [resume-requests.json](resume-requests.json) retains the exact next prompts, references and destinations for all 50 missing assets. No paid API fallback was used. Existing live SFF/AIR/gameplay files remain byte-identical to their backups. Fresh gameplay recordings remain deferred.

Accepted output PNGs, extracted poses, exact generation prompts/metadata, original pixel pose templates, complete source mappings and immutable runtime backups are under `characters/naruto/art/comic-style-v10` and `characters/saitama/art/comic-style-v10`. "Accepted" here means saved output; final visual and native validation still follows completion of the full set.

Current browser review checks every saved before/after pose and all sheet images on desktop and narrow viewports. [browser-validation.json](browser-validation.json) records those results. [progress.json](progress.json) records missing work and checksums proving the production runtime is unchanged. The installer refuses incomplete conversions; [preflight-validation.json](preflight-validation.json) checks that refusal without touching live artwork.

Resume with built-in imagegen after its usage limit resets. Inspect each template and the accepted form reference before generation. Save exact prompts and original generated paths, copy outputs into the workspace, run `save-native-style-v10.py`, then visually check anatomy, pose order, costumes and complete silhouettes. Do not regenerate saved sheets unless correcting a concrete problem. Do not use API/CLI fallback without explicit new authorization. Once all sheets and portraits are ready, use `install-native-style-v10.py` to preserve current native commands, CNS files, damage, sounds, timing and collision boxes while replacing the drawings and compensating AIR image-resolution scales.

The installer and conversion are prepared but have not run against production. Naruto's SFF1 will be re-encoded losslessly into SFF2 to support RGBA art; unrelated effects must compare pixel-for-pixel. Saitama's existing SFF2 can be derived in place. After installation, refresh shared roster/size previews, normalize optional AIR empty fields in the existing timeline validator, verify original frame sequences and state hashes, and perform native startup/transform checks without gameplay recording. Do not run the historical importers or recording scripts, which restore old baselines or generate deferred footage.
