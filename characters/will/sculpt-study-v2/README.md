# Second local head study

Editable Blender revision of the first head study. This remains a likeness
experiment; it is not an approved Will skin or an Unreal capture.

The head includes a named proportion shape key for a narrower jaw, wider mouth,
fuller lip region, relaxed upper eyelids and more prominent ears. Brows and
moustache follow the revised surface. A close scalp cap and modeled curl clusters
replace the old broad hair shell. Starting human topology remains MPFB-derived.

Open `will-head-toon-review.blend` for the shaded review, or
`will-head-shape-study.blend` for the editable geometry before toon conversion.
The front, three-quarter and profile PNGs are actual Blender renders.
The original study is preserved in `../sculpt-study-v1`.

No paid tools, uploads, photo skin projections, face rig or Unreal changes.
The Blender shader is not an Unreal material. Native artifact validation does
not establish facial likeness or animation readiness.

Rebuild with Blender's background Python using `scripts/revise-will-head-study.py`,
then `scripts/render-will-toon-study.py -- --study-dir characters/will/sculpt-study-v2`.

Review findings: the face still reads as generic. The hairline has visible
cap boundaries, especially in profile, and the curls form repetitive rows.
Lip and eyelid shapes remain too simplified. These renders are work in progress,
not a completed likeness milestone.
